# HexiYuan Garden 项目重构计划

## 一、重构目标

### 核心目标

1. **重新设计视觉风格** - 打造更现代、更美观的 UI 设计系统
2. **全面升级技术栈** - 引入新工具和最佳实践
3. **MVP 快速落地** - 聚焦核心功能，快速交付可用版本
4. **改善代码质量** - 提高可维护性、可测试性和可读性
5. **增强用户体验** - 优化交互设计、提升性能

### 关键决策

* **AI 助手**：集成第三方 AI 平台（**Vercel AI SDK / LangChain.js**）

* **数据模型**：从 Entry 统一模型拆分为独立模型

* **实施方式**：先设计后开发

***

## 二、当前架构分析

### 2.1 技术栈现状

| 类别  | 当前技术                | 版本     |
| --- | ------------------- | ------ |
| 框架  | Next.js             | 14.2.5 |
| 数据库 | SQLite + Prisma     | 7.8    |
| 样式  | Tailwind CSS        | 3.4    |
| 动画  | Framer Motion       | -      |
| AI  | 智谱 glm-4-flash/硅基流动 | -      |
| 认证  | JWT (jose)          | -      |

### 2.2 当前问题

#### 数据模型问题

* Entry 统一多态模型导致类型定义复杂

* 查询逻辑需要大量类型判断和条件分支

* 子表关联关系不够清晰

#### 组件问题

* 页面间存在大量重复代码

* 缺乏统一的组件设计规范

* 业务组件与 UI 组件耦合

#### 状态管理问题

* 客户端状态分散在各组件

* 服务端状态缺乏统一管理

* 表单状态处理不统一

#### UI 问题

* 设计系统不完善

* 响应式设计不足

* 视觉层次不够清晰

## 三、新架构设计

### 3.1 数据模型重构

#### 拆分方案

将 Entry 统一模型拆分为独立模型：

```
├── Experience（工作经历）
│   ├── id, company, position, startDate, endDate
│   ├── summary, content, tags
│   └── projects[]（关联项目）
│
├── Project（项目）
│   ├── id, title, slug, status
│   ├── repoUrl, demoUrl, techStack
│   ├── summary, content, coverImage
│   └── experience?（所属经历）
│
├── Travel（旅行）
│   ├── id, title, destination
│   ├── startDate, endDate, coverImage
│   ├── summary, content, tags
│   └── dayPlans[]（日程安排）
│
├── DayPlan（日程）
│   ├── id, date, location
│   ├── content, images
│   └── travel（所属旅行）
│
├── LifeEvent（生活事件）
│   ├── id, title, date
│   ├── category, content, images
│   └── tags
│
├── Knowledge（知识库）
│   ├── id, title, url
│   ├── category, tags
│   └── notes（笔记）
│
└── Tag（标签）
    └── id, name, slug, category
```

#### 优势

* 类型定义更清晰，无需复杂的多态判断

* 查询更直观，每个模型独立查询

* 关联关系更明确

* 便于后续扩展

## 四、UI 设计系统

### 4.1 设计原则

1. **简洁清晰** - 减少视觉噪音，突出核心内容
2. **层次分明** - 通过颜色、大小、间距建立视觉层次
3. **响应式优先** - 移动端优先，适配各种屏幕
4. **无障碍** - 符合 WCAG 2.1 AA 标准

### 4.2 色彩系统

#### 主色调（科技翡翠绿）

```css
--primary-50: #f0fdf4;
--primary-100: #dcfce7;
--primary-500: #22c55e;
--primary-600: #16a34a;  /* 主色 */
--primary-700: #15803d;
```

#### 中性色

```css
--gray-50: #fafafa;
--gray-100: #f4f4f5;
--gray-800: #27272a;
--gray-900: #18181b;
--gray-950: #09090b;  /* 背景 */
```

#### 语义色

```css
--success: #22c55e;
--warning: #f59e0b;
--error: #ef4444;
--info: #3b82f6;
```
